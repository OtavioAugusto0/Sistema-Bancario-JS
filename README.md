# 🏦 Sistema Bancário em JavaScript

Projeto desenvolvido em **JavaScript** com o objetivo de praticar conceitos de **Programação Orientada a Objetos (POO)** e lógica de programação.

## 📌 Sobre o projeto

O sistema simula operações básicas de um banco através do terminal.

Atualmente, o projeto permite realizar operações como:

* Criar uma conta
* Realizar depósitos
* Realizar saques
* Consultar saldo
* Registrar operações no extrato
* Validar saldo antes de realizar um saque

## 🛠️ Tecnologias utilizadas

* **JavaScript**
* **Node.js**
* **Git e GitHub**

## 📚 Conceitos praticados

Durante o desenvolvimento, estão sendo utilizados conceitos como:

* Classes
* Objetos
* Construtores
* Métodos
* `this`
* Arrays
* Objetos dentro de arrays
* Condicionais (`if/else`)
* Template Strings
* Validação de operações
* Manipulação de dados

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/OtavioAugusto0/Sistema-Bancario-JS.git
```

### 2. Entre na pasta

```bash
cd Sistema-Bancario-JS
```

### 3. Execute o projeto

```bash
node treino.js
```
